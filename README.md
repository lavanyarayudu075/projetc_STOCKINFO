# 📊 Stock Dashboard – Power BI Project

## 🔍 Project Description
This project presents an interactive **Stock Market Dashboard** created using **Power BI**.  
It helps analyze stock performance, trends, and key metrics through visual insights.

## 🎯 Key Insights
- Stock performance overview
- Trend analysis
- Key KPIs visualization
- Interactive filters and slicers

## 🛠 Tools Used
- Power BI
- Excel / CSV (Data Source)
- post man api
- finnhub.io
- sharepoint
- power automate

## 📁 Repository Structure
- `dashboards/` → Power BI (.pbix) file  
- `images/` → Dashboard screenshots  
- `presentation/` → Project PPT / PDF  

## ▶️ How to View the Dashboard
1. Download the `.pbix` file from the **dashboards** folder
2. Open it using **Power BI Desktop**
